# UX Issues — Internal Feedback

_Internal feedback about Tosca Cloud. IN-001…IN-023 come from an unstructured running list from a single unnamed internal source; IN-024…IN-025 are behavioural hypotheses derived from Microsoft Clarity session analytics (Name `MS Clarity`)._
_One row per entry — no overlap grouping._
_Each Description is close to the source text; Environment is `N/A` for every row. Name is `Internal feedback` for IN-001…IN-023 and `MS Clarity` for IN-024…IN-025._
