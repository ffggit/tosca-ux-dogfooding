# UX Issues — Overlap Consolidation (OVL)

_This file consolidates **10-allissues.md** by merging only the issues that describe **the same problem at the same locus**, following **ruleset v2** (problem/description-centric; ordered Gates 0–6; default BORDERLINE → DO NOT MERGE)._
_**Fixes were NOT used as a merge criterion** — the "Fix hypothesis" column was ignored when deciding; merges are grounded solely in the Description (supported by Screen/page/component + Flow/step)._
_Every one of the **328** source IDs appears **exactly once**: either inside exactly one OVL's "Merged IDs" cell, or as exactly one row in the Unique issues table. Consolidation is deliberately conservative — the large majority of issues remain unique._
_**Accounting:** 11 OVL groups covering 31 source IDs + 297 unique singletons = 328. (Designers 126 = 8 merged + 118 unique · Testing Community 108 = 8 merged + 100 unique · Gainsight 69 = 8 merged + 61 unique · Internal 25 = 7 merged + 18 unique.)_
